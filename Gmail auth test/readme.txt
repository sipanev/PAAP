1. Create a new Google app or use an existing one.
2. Register a new Google OAuth 2.0 Client ID.
3. Download the client secret file, save a copy in this folder and change the name to "client_secret.apps.googleusercontent.com.json".
 -- or you could use an existing one, if you have it already.
4. Run the Python script.
5. A new browser window should open; grant access and the token will be saved locally.
